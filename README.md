# Hi, I'm Allan

Just tinkering — mostly homelab stuff and reviving other people's abandoned projects when I find one
with good bones.

Recent-ish: fixed a webhook auth gap in [Placeholdarr](https://github.com/TheIndieArmy/placeholdarr)
and it got merged upstream, keeping a seerr-roku fork alive, and picking up a stalled Nuxt dashboard
([reaparr](https://github.com/i-machine-arr/reaparr)) to add the disk-cleanup feature it never got.

Runs on a pretty modest setup — a low-spec laptop that also doubles as a boat chartplotter, and a
TrueNAS box at home doing the heavier lifting. Nothing fancy, just stuff that works.

I use AI tools a lot in how I build this stuff, and I try to keep that honest rather than pretend
otherwise — real testing before anything ships, not just taking a first draft at face value.
